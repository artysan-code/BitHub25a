# Programmazione Java per Dispositivi Mobili
Corso del terzo anno sulla programmazione Java per dispositivi mobili.
## Modalità d'esame
Secondo la scheda DidatticaWEB dell'insegnamento affine tenuto da Loreti (A.A. 2025/2026) la valutazione è scritta e orale; insegnamento frontale, 6 CFU, senza obbligo di frequenza.
- **Prerequisito**: basi di programmazione.
- Obiettivi: elementi essenziali della programmazione a oggetti attraverso due casi reali, i dispositivi mobili Android e i server web Java.
- Il dettaglio di svolgimento delle due prove non è indicato nella scheda.
## Programma e Appunti
Programma del corso ancora da completare. Gli appunti non ci sono ancora.
